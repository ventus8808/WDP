BRMS Analysis Pipeline - Refactored ArchitectureThis directory contains a refactored Bayesian multilevel regression pipeline using the brms package in R. The architecture has been redesigned following the "responsibility inversion" principle for improved maintainability and robustness.Architecture OverviewSimple Orchestrator (Python): 03_main_runner.py reads config.yaml, finds active scenarios, and calls the R modeling script for each one. It is simple and does not know any data-specific details.Intelligent Engine (R): 02_run_brms_model.R receives a single scenario_name, reads the full configuration from config.yaml itself, and performs all necessary data filtering, variable selection, and model fitting. It saves unique, atomic output files for each run.Filesutils.R: Centralized utility functions for configuration loading.01_prepare_data.R: A one-time script to perform initial data cleaning and preparation. Run once or whenever raw data changes.02_run_brms_model.R: Intelligent modeling script. The core engine of the analysis.03_main_runner.py: Simple orchestration script. The main entry point to run all analyses.04_process_results.R: Consolidated post-processing script. Aggregates all model outputs, creates visualizations, and generates final reports, including the LMM-compatible format.WorkflowStep 1: Configure Your AnalysisEdit config.yaml to define which analyses to run. Set active: true for desired scenarios. This is the only file you need to edit to control the entire pipeline.To run a single test case (e.g., for one cancer type):Set active: true for that one scenario and active: false for all others.brms_analysis:
  scenarios:
    - name: "LungCancer_TotalEQI_Lag5_AllRUCC"
      active: true  # Run this one
      # ... other parameters
    - name: "BreastCancer_TotalEQI_Lag5_AllRUCC"
      active: false # Skip this one
      # ... other parameters
Step 2: Run the PipelineExecute the main runner from your terminal. It will automatically handle data prep, run all active model scenarios, and process the results.python Code/brms/03_main_runner.py
Step 3: Check the ResultsAll outputs are saved in the Result/brms/ directory, organized into subfolders:model_fits/: Full brms model objects (.rds).csv_outputs/: Raw CSV summaries for each individual model run.figures/: Final plots, like forest plots comparing effects across scenarios.reports/: Final aggregated summary tables, including the LMM-compatible output file.
